# Landing Page For A Restaurant

This is a simple and responsive landing page for a restaurant, built using HTML, CSS, and JavaScript. The page showcases the restaurant's offerings, ambiance, and contact details with an attractive UI.

## Live Demo
Check out the live project at:
[Landing Page for a Restaurant](https://amanbahuguna03.github.io)

## Technologies Used
- **HTML**: Structuring the webpage content.
- **CSS**: Styling the page for a visually appealing design.
- **JavaScript**: Adding basic interactivity and animations.

## Features
- Responsive design for mobile and desktop users.
- Eye-catching UI with smooth transitions.
- Basic JavaScript for interactive elements.
- Sections for menu, about, contact, and more.

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/amanbahuguna03/Landing-Page-For-A-Restaurant.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Landing-Page-For-A-Restaurant
   ```
3. Open `index.html` in your browser.
